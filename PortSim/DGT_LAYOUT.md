# 부산 신항 7부두(DGT) 배치

## 규모와 출처

- 운영사 시설 현황: https://info.dgtbusan.com/DGT/terminal/facility
- 안벽 길이 1,050m, 면적 837,201㎡를 사용한다. 부지는 같은 면적의 1,050 × 797.334m 직사각형으로 근사했다. 실제 지적 경계 재현은 아니다.
- 운영사 배치 설명: https://www.dgtbusan.com/DGT/terminal/feature — 수직형 야드. 야드 블록의 긴 방향을 안벽에 수직으로 배치했다.
- 사용자 첨부 `img_bsport_0801.jpg`는 시설 종류와 상대적 위치 참고이며 DGT의 측량도라고 간주하지 않는다. 운영동, 작업자 대기소, 정비동, 게이트, CIS, 주변전소, 냉동 컨테이너, 비규격 화물, 공컨테이너, 수리 세척장을 반영했다.
- 건물 치수·상세 위치·블록 수·장비 수는 시각화용 추정이다. 실제 DGT 설비 수량이나 운영 동선의 검증 모델은 아니다.

## 좌표와 액터

Unreal 1 unit = 1cm. X는 육지 방향, Y는 안벽 방향, Z는 높이이다. `TerminalLayout.h`가 부지와 작업 야드의 치수를 관리한다. 부지 지표 높이는 20cm이며, 전체 맵은 기존처럼 게임 시작 시 생성된다. `.umap`에 저장된 수동 배치가 아니다.

- 선박 3척 배치: 중앙 작업 선박은 약 297 × 45m, 양측 배경 선박은 약 292 × 45m. 양측 선박 중심 간격 700m.
- 야드: 18블록, 블록당 30베이 × 7열, 2~4단 컨테이너. 컨테이너는 12.192 × 2.438 × 2.59m. 야드와 도로의 전체 배율을 컨테이너에 적용하지 않는다.
- 주변 작동 RMG: 블록당 2기, 레일 간격 32m, 다리 높이 22m. 작업 RMG는 기존 90m 폭에서 45m로 축소하고 24개 목적지 좌표도 함께 축소했다.
- 주변 작동 STS: 8기, 30m 레일 간격, 상부 보 높이 57m. 중앙의 기존 작업 STS 1기는 기존 30m 작업 높이와 하역 물리 설정을 유지한다.
- 작업용 컨테이너 24개·AGV 3대·RMG 1기·선박 1척의 기존 액터 및 왕복 하역 기능을 유지한다. 작업 선박 갑판 높이도 기존 물리 인계 위치를 유지한다.
- 주변 RMG 36기와 STS 8기는 `APortWorkingCrane` 독립 액터이며, 각자 고유 컨테이너 1개를 지정된 두 슬롯 사이에서 왕복 이송한다. 게임 시작 시 자동으로 운전한다. 인양·트롤리·갠트리 속도를 제한하고, 안전 높이에서 수평 이송 후 목적지에 내려놓는다.
- 실제 `APortContainerActor` 44개가 추가된다. 픽업 정렬·정지 상태와 목적지 충돌을 검사하고, 스프레더에 결합한 동안은 구동 운동을 사용한다. 해제 후 Chaos 물리로 지지판 위에 내려놓으며 적치 위치·속도·기울기를 확인한다. 로프 흔들림의 동역학은 중앙 훈련 STS에만 적용된다.
- 각 RMG의 두 작업 슬롯에 있던 배경 스택을 비우고, STS는 선박 해측 마지막 열을 비워 실제 작업 화물을 배치한다. 크레인별 예약 구간은 겹치지 않는다. 일반 야드 재고를 자동 선택하는 스케줄러나 추가 AGV 연계는 아직 없으며 지정 슬롯 왕복 작업이다.
- 건물·선체·작업 대상 외 적재 컨테이너는 HISM으로 유지한다. 이 배경 인스턴스에는 충돌이 없고, 실제 작업 화물·크레인 다리·슬롯 지지판·지면에는 충돌이 있다.
- `Working_RMG_*` / `Working_STS_*` 액터에서 CraneID, Stage, CompletedJobs, CargoActor, Fault 상태를 확인할 수 있다. bEnabled로 각 크레인을 정지할 수 있다. P는 전체 일시정지, Space는 전체 비상정지, R은 화물과 모든 작업 상태를 초기화한다.
- 리셋 시 배경을 중복 생성하지 않으며 종료 시 배경 액터를 정리한다.

## 카메라

- 시작 화면 / Home: 전체 부지 조감도.
- End: 중앙 하역 작업 구역.
- Tab: 주변 크레인 44기 순차 근접 보기. 자동 캡처는 -PortSimSiteFocus=0 (첫 RMG), -PortSimSiteFocus=36 (첫 주변 STS) 옵션을 사용할 수 있다.
- Page Up / Page Down: 거리 비례 확대·축소.
- 방향키: 회전·기울기.
- U / L: 중앙 양하·적하, P: 전체 일시정지, Space: 전체 비상정지, R: 전체 리셋.

## 검증

UE 5.6 Editor 빌드 후 기존 `Scripts/TestTerminal.ps1`로 24개 양하·24개 적하, 물리 슬롯, 일시정지·비상정지·리셋을 확인한다. `-PortSimCapture -PortSimHUDHidden` 실행으로 전체 배치 스크린샷을 확인한다.

주변 장비 검증은 Scripts/TestSite.ps1로 실행한다. 44기 모두의 왕복 2회 이상 적치, 고유 화물 ID, 예약 범위, 일시정지·비상정지, 운반 중 리셋과 액터 중복을 검사한다. 전용 재질 재생성은 Scripts/create_site_materials.py를 Unreal Python commandlet으로 실행한다.

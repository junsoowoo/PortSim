# PortSim 항만 관제실

프로젝트의 실제 액터 상태와 STS 레퍼런스를 읽는 로컬 웹 대시보드. 외부 서비스나 npm 패키지 없이 Node.js로 실행한다.

## 실행

저장소 루트의 PowerShell에서:

```powershell
./PortSim/Scripts/LaunchDashboard.ps1
```

또는 `node Dashboard/server.mjs` 후 브라우저에서 `http://127.0.0.1:4173`을 연다. 서버는 이 PC의 loopback에만 바인딩한다. 종료는 실행 창의 Ctrl+C. 다른 포트는 `LaunchDashboard.ps1 -Port 4174`.

엔진을 빌드하고 시뮬레이션을 실행하면 `PortSim/Saved/Dashboard/state.json`이 벽시계 기준 약 1초마다 원자적 교체 방식으로 갱신된다. 웹의 갱신 속도는 엔진 센서의 20 Hz 샘플 주기와 다르다. 엔진을 종료하면 마지막 기록을 조회하며, 5초 이상 갱신이 없으면 실시간 표시를 해제한다. 동시에 여러 PIE/테스트 인스턴스를 실행하면 같은 파일에 기록하므로 대시보드 조회 시 하나만 실행한다.

## 화면

- **항만 모니터링**: STS·AGV·RMG·선박·야드 지도 및 액터 목록. 좌표는 엔진 값이며 지도 기호/배경은 축척이 다른 도식이다.
- **장비 탐색기**: 유형 필터, 이름/ID 검색, 페이지 이동. 액터 선택 시 현재 동작·화물·거리·하중·변수·공개 속성·구성 부품 좌표·원본 JSON 조회. 모든 월드 액터를 조회하며, 인스턴스 야드 화물은 18개 블록으로 집계한다. 선박 3개는 매니페스트를 집계한 논리 그룹이다.
- **센서 레퍼런스**: 센서 14종의 대표적 부착 부위·관측 항목·제어 목적. 정확한 설치 좌표/범위가 null이면 미확정. 입력하는 범위는 설명용 가정이며 엔진에 쓰지 않는다.
- **시간 절감 분석**: 선박 1척의 기준 시간·물량·STS 수 입력. 자동화 전체 완료 기록 또는 명시적인 직접 입력 시나리오와 비교한다. 기준값은 브라우저에만 보관한다.
- **스냅샷 저장**: 현재 엔진 기록과 비교 입력을 JSON으로 내려받는다.

## 시간 비교 규칙

통합 모드에서 선박별 첫 작업 배정 시각을 시작으로 한다. `unloaded_at`은 해당 선박 마지막 화물의 STS→AGV 인계 완료 시각, `placed_at`은 마지막 야드 적재 시각이다. 양쪽은 이벤트가 발생한 시뮬레이션 프레임에 기록하고 초기화 시 지운다. 시각은 배속이나 컴퓨터 실행 시간과 무관하며 일시정지/대기를 포함한다.

`절감률 = (기준 시간 - 자동화 시간) / 기준 시간 × 100`

전체 화물 완료 전에는 절감률을 외삽하지 않는다. 다른 물량/STS 수는 비교를 막는다. 화물 질량·적층·경로·휴식 포함 여부 등 나머지 조건은 동일하게 맞춰 입력해야 한다. 18건 회귀 테스트는 1,584건 전체 완료의 근거가 아니다. 음수 절감률은 자동화 시간이 더 길다는 뜻이다. 레거시 중앙 시험은 선박별 비교 대상에서 제외한다.

## 데이터 범위

`Document/STS/STS_ReferenceData.json`과 `PortSim/Config/STS_Simulation.json`을 읽으며, 실행 기록이 있으면 **실제로 적용된 프로파일 스냅샷**을 우선 표시한다. 사이트 STS는 수평 스프레더 운동학 모델, 코너 하중은 질량/CoG 기반 준정적 추정값이다. 바쁜 작업이 없는 센서는 이전 관측을 실시간 값처럼 보여주지 않는다.

개별 와이어 장력·모터 토크·anti-sway/anti-skew 상세 물리는 아직 엔진에 없다. 해당 탭은 구현 상태와 필요한 자료를 표시한다. AGV의 센서 모양 메시를 LiDAR 관측 모델로 간주하지 않는다. 이 웹 앱은 읽기 전용이며 엔진 운전 명령이나 설정 변경 API를 제공하지 않는다.

## 검증

```powershell
node --test Dashboard/tests/*.test.mjs
node Dashboard/tests/telemetry.mjs
```

두 번째 검사는 통합 모드 실행 후 실제 스냅샷의 액터 수·단위·프로파일·코너 하중 합을 확인한다.

2026-09-24 검증: UE 5.6 빌드 및 `TestSite.ps1 -Mode Normal` 18건 운반 통과(마지막 야드 배치 644.450010 시뮬레이션 초). 계산 규칙 6개 테스트와 실제 스냅샷 검사 통과. 브라우저에서 지도 장비 선택, 화물 검색/변수 조회, 센서 선택/범위 도식, 미완료 작업 차단, 직접 입력 10시간→6시간의 40% 계산, 물량 불일치 차단 및 390px 화면을 확인했다. 비교 입력의 테스트 값은 초기화했다. 전체 1,584개 하역 완료 및 상세 물리 솔버 검증은 포함하지 않는다.
